# Race Strategy

**Race Strategy** (Definitive Sim Racing Strategy) is a race engineer and strategist for sim racing: fuel and tyre
plans, live pit calls by voice, and a pit wall for Le Mans Ultimate, AC EVO, ACC, Assetto Corsa and RaceRoom.
It runs on its own or as the Race Strategy card inside **WND SimSuite**.

## Download

- **Latest release:** see [Releases](https://github.com/WnDTech/RaceStrategy/releases/latest)
- **Website:** [simsuite.wndtech.tips](https://simsuite.wndtech.tips/strategy.html)
